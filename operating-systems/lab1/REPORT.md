# Отчёт по лабораторной работе

## Цель

Установить инструменты для разработки на C, собрать программу вручную и с помощью системы сборки CMake на двух операционных системах.

## Система 1

- Операционная система: macOS 26.6.2, arm64
- Компилятор и версия: Apple Clang 21.0.0
- Make и версия: GNU Make 3.81
- CMake и версия: CMake 4.4.4

### Однофайловая программа

Команда компиляции:

```text
clang -std=c11 -Wall -Wextra -Wpedantic hello_single.c -o hello_single
```

Результат запуска:

```text
$ ./hello_single
Hello, World!
```

### Многофайловая программа и CMake

Команды и результат:

```text
$ cmake -S . -B build
-- Configuring done
-- Generating done

$ cmake --build build
[100%] Built target hello

$ ctest --test-dir build --output-on-failure
1/1 Test #1: hello_output ... Passed
100% tests passed, 0 tests failed out of 1
```
