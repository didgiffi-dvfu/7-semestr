# Шпаргалка по сборке C++ проектов (CMake, MinGW, Git)

Памятка со всеми базовыми командами для сборки многофайловых C++ проектов в Windows и Kali Linux.

---

## 1. Структура многофайлового проекта

Типичная структура файлов перед началом сборки:

```text
lab_0/
├── CMakeLists.txt     # Инструкция для CMake по сборке проекта
├── main.cpp           # Главный файл (точка входа)
├── hello.h          # Заголовочный файл (объявления функций)
└── hello.cpp        # Файл реализации (код функций)
```

---

## 2. Команды для сборки проекта через CMake

Все команды выполняется из терминала (PowerShell / Command Prompt / Bash):

| Команда                                                    | Описание                                                                                                          |
| :--------------------------------------------------------- | :---------------------------------------------------------------------------------------------------------------- |
| `mkdir build`                                              | Создает отдельную папку `build` для файлов сборки (чтобы не мусорить рядом с кодом).                              |
| `cd build`                                                 | Переходит в созданную папку `build`.                                                                              |
| `cmake ..`                                                 | **Генерация:** CMake ищет файл `CMakeLists.txt` на уровень выше (`..`) и подготавливает файлы сборки под вашу ОС. |
| `cmake --build .`                                          | **Компиляция:** Запускает сборку и создаёт готовый исполняемый файл из сгенерированных конфигураций.              |
| `.\my_program.exe` _(Windows)_<br>`./my_program` _(Linux)_ | Запускает полученную готовую программу из текущей папки.                                                          |
| `cd ..`                                                    | Возвращает вас на один уровень вверх из текущей папки.                                                            |

> **Совет:** Если CMake выдает ошибку о несоответствии файлов или отсутствии компилятора, бывает полезно полностью очистить содержимое папки `build` и повторить шаг `cmake ..`.

## 3. Команды Git (Синхронизация с Kali Linux)

### Отправка изменений с Windows:

1. `git status` — проверить, какие файлы были изменены или созданы.
2. `git add .` — подготовить все изменения к сохранению (индексация).
3. `git commit -m "feat: setup cmake multifile project"` — зафиксировать изменения с сообщением.
4. `git push origin main` — отправить сохранённый код на GitHub / GitLab.

### Получение и запуск в Kali Linux:

1. `git pull` — скачать свежие изменения из репозитория.
2. `mkdir build && cd build` — создать и перейти в папку `build`.
3. `cmake ..` — сгенерировать конфигурацию под Linux.
4. `cmake --build .` — скомпилировать исполняемый файл для Linux.
5. `./my_program` — запустить программу.

## 4. Шпаргалка по файлам и синтаксису

- **`.h` (Header file):** Оглавление/витрина модуля. Включает макрос `#pragma once` (или `#ifndef`), чтобы файл случайно не подгружался дважды.
- **`.cpp` (Source file):** Текст функций и их реальная математическая/программная логика.
- **`CMakeLists.txt`:**
  - `add_executable(название_программы файл1.cpp файл2.cpp)` — главная строчка, куда обязательно нужно вписывать **все** файлы с расширением `.cpp`.
